# progetto-psd-aula-studio-prenotazioni
Progetto di un programma di ausilio a gestire un'aula studio di dimensione prefissata.

Da eseguire su sistema Linux (Ubuntu) (creato con nano, tramite WSL (Windows SubSystem for Linux)).

La cartella che inizialmente è praticamente vuota, object, alla compilazione del make ha tutti i file oggetto a disposizione.

Scrivere semplicemente "make" per compilare e poter avviare il progetto con ./gestore_aula

Per avviare invece la test suite, ./test_gestore

Linguaggio: Standard C99.

Disponibile anche comando "make clean" per pulire i file oggetto (in cartella object) e file eseguibili.
